# Данные: экспорт корейской косметики (HS 3304), 2015–2026

Таможенная статистика Кореи по экспорту косметики HS 3304 — по всем странам мира и отдельно по странам региона СНГ.

## Файлы

| Файл | Что внутри | Стран | Строк |
|---|---|---|---|
| `customs_HS3304_WORLD_2015-01_2026-10.csv` | экспорт из Кореи по **всем странам** | 228 | 19 003 |
| `customs_HS3304_CIS_2015-01_2026-10.csv` | то же, только **9 стран региона** | 9 | 1 254 |

CIS-файл — подмножество WORLD-файла: значения по этим 9 странам совпадают 1:1.

- **Источник:** 관세청 수출입무역통계 (таможенная служба Кореи), [tradedata.go.kr](https://tradedata.go.kr) → 수출입 실적 → 품목별+국가별
- **Товар:** HS 3304 — косметика для макияжа и ухода за кожей (включая солнцезащитные средства), средства для маникюра и педикюра. Без разбивки на подкоды.
- **Период:** 2015-01 – 2026-10, помесячно (142 месяца, все месяцы на месте).
- **Дата выгрузки:** 22–23.11.2026.

## Колонки

| Колонка | Перевод | Единицы |
|---|---|---|
| `기간` | период | `YYYY-MM` |
| `국가` | страна (по-корейски) | — |
| `HS코드` | код товара | `3304` (читать как строку) |
| `품목명` | название товара | — |
| `수출 중량` | экспорт, вес | тонны |
| `수출 금액` | экспорт, стоимость | тыс. USD |
| `수입 중량` | импорт в Корею, вес | тонны |
| `수입 금액` | импорт в Корею, стоимость | тыс. USD |
| `무역수지` | торговый баланс | тыс. USD |

Цена за кг: `수출 금액 / 수출 중량` (тыс. $ / тонны = $/кг).

## Как собраны
- Сайт отдаёт максимум 12 месяцев за раз, поэтому каждый файл склеен из 12 выгрузок.
- Строки `총계` (итог каждой выгрузки) удалены.
- Проверено: полных дублей и пересечений периодов нет; сумма по каждой выгрузке совпадает с её `총계` (расхождение до 24 тыс. $ из-за округления).
- Исходные выгрузки не изменялись.

## Пропуски
В CIS-файле отсутствуют **24 пары «страна × месяц»** (2015–2018, в основном Грузия и Армения). Скорее всего, в эти месяцы экспорта не было: таможня не публикует строки с нулевым экспортом. В файле они не заполнены.

Это касается и WORLD-файла: страна появляется в месяце только если в неё что-то экспортировали.

## Загрузка в pandas
```python
import pandas as pd

df = pd.read_csv('customs_HS3304_WORLD_2015-01_2026-10.csv',
                 encoding='utf-8-sig', dtype={'HS코드': str})
df['date'] = pd.to_datetime(df['기간'])
df['tons'] = df['수출 중량']
df['usd_k'] = df['수출 금액']
df['usd_per_kg'] = df['usd_k'] / df['tons']
```
Кодировка — `utf-8-sig` (иначе корейские названия и первая колонка прочитаются криво).
